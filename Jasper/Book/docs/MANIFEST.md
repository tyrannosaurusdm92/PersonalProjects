# Package manifest

- Root entry point: `index.html`
- Reader styles: `css/book.css`
- Linear reader: `js/app.js`
- Offline story data: `js/fanfic-data.js`
- Source chapter JSON: `json/<fandom>/<series>/<chapter>.json`
- Series catalogs: `json/<fandom>/<series>/series.json`
- Reading index: `json/authored-library-index.json`
- Content review: `docs/CONTENT_AUDIT.json`

The library contains five complete stories and 200 chapters, rated Teen. Chapters follow one fixed reading order. No story creation, branch, import, or private-scene generator is loaded by the reader.
