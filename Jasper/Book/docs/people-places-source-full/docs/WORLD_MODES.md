# World Modes

`generator.html` exposes three independent checkboxes: Realistic, Fantasy and Sci-Fi / Aliens. One, two or all three may be active.

Dominance hierarchy:

1. Sci-Fi / Aliens — dominant whenever selected.
2. Fantasy — secondary dominant when Sci-Fi is also active and dominant when Sci-Fi is absent.
3. Realistic — dominant only when selected alone.

The hierarchy shapes world population and location infrastructure while each individual person keeps their own generated mode context.
