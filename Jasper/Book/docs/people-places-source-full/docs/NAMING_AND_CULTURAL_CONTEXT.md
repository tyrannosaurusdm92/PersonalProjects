# Naming and Cultural Context

Realistic names use locale/language context and culture-aware name structures. First, additional given, middle, patronymic, lineage and family-name components remain distinct where relevant. Name generation is not derived from skin tone, personality, job, class, hobbies, gender identity, pronouns, sexuality, relationship framework, disability or behavior.

Fantasy and science-fiction people use original fictional phonotactic profiles rather than mapping nonhuman species onto real-world ethnic groups.
