# Architecture

The runtime is organized around two entity families: `person` and `place`. Supporting modules exist only to deepen those entities or interactions between them.

Person modules cover identity, culturally contextual names, physical description, personality, interests, mood, life context, work/education, relationships, social graphs, routines, memory, knowledge and conversation. Place modules cover realistic and speculative location generation, geography, ambience, access, occupancy and assignments. World modules connect people to homes, work, school, movement and time.

The UI is text-first. It displays descriptions and structured data; it does not construct a visual body or avatar.
