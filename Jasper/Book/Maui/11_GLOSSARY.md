# Reference glossary (contextual, introductory)

Definitions are **short orientation notes**, not substitutes for a fluent speaker or expert on a particular iwi's context. Macrons matter. Avoid fabricated translations in dialogue.

| Term | Introductory meaning / context |
|---|---|
| **Aotearoa** | Māori name commonly used for New Zealand; contexts and history of use vary. |
| **Māori** | Indigenous people(s) of Aotearoa; not a synonym for every Polynesian culture. |
| **Iwi / hapū / whānau** | People/tribe; subtribe/kin group; family/extended family, context dependent. |
| **Māui-tikitiki-a-Taranga** | Name of Māui referring to Taranga's topknot in a well-known birth tradition. |
| **Atua** | Deity, supernatural ancestor/presence, with contextual relationships. |
| **Whakapapa** | Genealogical/relational layering connecting people, places and the world. |
| **Mana** | Prestige, authority, influence, potency, obligation; not spell points. |
| **Tapu / noa** | Sacred/restricted state and ordinary/free-from-restriction state; not merely good/evil. |
| **Mauri** | Life principle, vital essence of beings and places. |
| **Wairua** | Spiritual aspect; translations vary. |
| **Kaitiaki / kaitiakitanga** | Guardian and guardianship/stewardship with relationship and responsibility. |
| **Rāhui** | Restriction/prohibition, sometimes to protect a resource or place. |
| **Tikanga / kawa** | Appropriate customs/practice and often local formal protocol. |
| **Marae / wharenui** | Communal ceremonial meeting complex/space; meeting house. |
| **Pōwhiri** | Formal welcome, with sequence differing according to context and hosts. |
| **Karanga** | Formal call in a welcome and other appropriate contexts. |
| **Wero** | Challenge that occurs in some formal welcomes. |
| **Whaikōrero** | Formal oratory. |
| **Waiata** | Song; has many subtypes and functions. |
| **Waiata aroha / tangi / oriori** | Love/longing song; lament; genealogically meaningful song to a child. |
| **Haka** | A range of powerful performed forms, not just war dances. |
| **Kapa haka** | Group Māori performance art, living and evolving. |
| **Poi** | Māori artform and instrument of ball and cord with multiple histories. |
| **Taonga pūoro** | Traditional Māori musical instruments and musical knowledge. |
| **Kōauau / pūtōrino** | Different types of flute/instrument with distinct uses. |
| **Hongi / harirū** | Ceremonial nose-press greeting / handshake. |
| **Koha** | Contribution/gift from visitors in many contexts. |
| **Karakia** | Prayer, invocation or ritual words depending on context. |
| **Tohunga** | Specialist/expert; sometimes ritual expert. |
| **Tangihanga** | Māori death/funeral practices, varying among communities. |
| **Taniwha** | Supernatural place-linked beings, sometimes dangerous, sometimes kaitiaki. |
| **Patupaiarehe / tūrehu** | Supernatural mountain/forest people in some traditions. |
| **Ponaturi** | Supernatural sea-related beings in some stories. |
| **Rarohenga** | Realm of the dead in relevant traditions; not Disney's Lalotai. |
| **Te Ika-a-Māui / Te Waka-a-Māui** | Māui's fish / his canoe; names tied to North and South Island traditions. |
| **Tamanuiterā** | The sun, an acting being in Māui's solar feat. |
| **Mānaiakalani** | Maui's fishhook in Hawaiian cultural and star traditions; not a Māori term or necessarily identical to Disney's hook. |
| **Tā moko** | Distinctive Māori tattooing art/identity practice. |
