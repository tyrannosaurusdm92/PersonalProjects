# Repositories used and source provenance

**External repositories used in this integration: none.** No public repository was cloned, downloaded, copied, or adapted. This package integrates only the two uploaded HTML sources and their original embedded code and textures.

- `william_azara_subtabs(1).html`: profile page, navigation, admin saving, page publishing.
- `Azara_Solar_System_and_Constellations_Natural_Coastlines_Nebulae_v7(2).html`: solar-system and constellation source, original texture payload, sky catalog, time system.

The uploaded astronomy document does not identify verifiable upstream repository URLs or licenses for each embedded module, so none are invented. Source-file and output-file hashes are recorded in `docs/manifest.json`. No external WebAssembly toolchain or third-party framework repository was required.
