GitHub Pages entry point
- index.html is the only HTML file and is used because Backend 2.1 generates share links to the Character-References folder root.
- The public share URL uses a six-digit hash such as #123456.
- The frontend validates that code with share.validate before displaying the visitor interface.
- Page navigation preserves a valid six-digit hash so it is not replaced by page names.
- #admin remains the only hash that reveals the private administrator interface.
