FINAL PACKET WORKFLOW

1. Open index.html#admin.
2. Sign in with the administrator email and one-time code.
3. Load the saved character references.
4. Attach the PDFs or images you want included.
5. Drag the document cards into the final order.
6. Build the final packet from selected references or all references.

The final packet places character references first, followed by document summaries, then the full supporting documents in the organizer order.

A reference writer can update the same response from the same browser while its saved editing access remains available. Reference writers cannot delete submissions. Administrator tools can review and delete responses, manage notification emails, create a reference-only PDF, and build the final packet.
