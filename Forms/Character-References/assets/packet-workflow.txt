FINAL PACKET WORKFLOW

1. Open index.html with #admin at the end of the address.
2. Sign in with the one-time code sent by the form system.
3. Refresh the collected references and select the references you want, or use all references.
4. Drag the supporting-document rows into the order you want.
5. Download the matching PDFs or images from Google Drive and attach them to the organizer.
6. Check that every included document shows as attached.
7. Build the final packet.

FINAL PDF ORDER

1. Cover
2. Character references
3. Supporting-document summaries
4. Full supporting PDFs and images in organizer order

Reference writers can update their own response from the same browser while its saved editing access is still present. The combined packet is built in the browser. Supporting files attached in the organizer are not uploaded to Apps Script.
